# Lumen Analytics FAQ

## Plans and Pricing

Lumen Analytics offers three plans. Basic costs $29 per user per month, Pro costs $79 per user per month, and Enterprise pricing is custom. Annual billing gives a 15% discount.

## Data Retention

Event data is retained for 13 months on the Basic plan and 36 months on the Pro plan. Enterprise customers can configure retention up to 7 years. Deleted projects are permanently purged after 30 days.

## API Limits

The REST API allows 100 requests per minute on Basic and 1,000 requests per minute on Pro. Requests above the limit receive an HTTP 429 response with a Retry-After header. Enterprise limits are negotiated per contract.

## Single Sign-On

SAML single sign-on is available on the Enterprise plan only. Pro customers can sign in with Google or Microsoft accounts.

## Exporting Data

Any dashboard can be exported to CSV or PDF. Scheduled weekly exports are available on Pro and Enterprise plans.
